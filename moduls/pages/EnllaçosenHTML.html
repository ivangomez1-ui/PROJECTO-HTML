Esta diapositiva aborda el uso de la etiqueta < a> para crear enlaces en HTML hacia páginas web, documentos o secciones de una misma página, donde el texto ubicado entre la etiqueta de apertura y la de cierre es el elemento visible y cliqueable por el usuario. Su atributo principal es href, el cual especifica la URL de destino mediante un enlace absoluto (URL completa) o relativo (ruta interna). Otro atributo relevante es target, que define dónde se abrirá el enlace, destacando valores como _self (la misma pestaña, por defecto) y _blank (una nueva pestaña). Entre las buenas prácticas indicadas se recomienda emplear textos de enlace descriptivos (por ejemplo, "Visita la página de Contacte" en lugar de "Clica aquí") para favorecer la accesibilidad y el SEO, utilizar target="_blank" solo cuando sea estrictamente necesario para evitar confundir a los usuarios, y garantizar siempre la accesibilidad del enlace para lectores de pantalla.
