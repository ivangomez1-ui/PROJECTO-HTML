HTML ofrece diversas etiquetas para dar formato al texto según su estilo y significado semántico:

Negrita: < b> aplica negrita solo visualmente, mientras que < strong> añade además importancia semántica al texto.

Cursiva: < i> aplica cursiva sin implicar énfasis, mientras que < em> añade énfasis e importancia al texto.

Subrayado: < u> sirve para subrayar texto.

Tachado: < strike> o < s> se usan para tachar texto, indicando que se ha borrado o ya no es relevante.

Superíndice y subíndice: < sup> eleva el texto (ideal para exponentes matemáticos) y < sub> lo coloca como subíndice (común en fórmulas químicas).
