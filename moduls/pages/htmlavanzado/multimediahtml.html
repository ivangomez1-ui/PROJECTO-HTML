HTML5 introduce la integración nativa de elementos multimedia (imágenes, vídeos y audio) sin requerir complementos externos como Flash, optimizando la compatibilidad y usabilidad en dispositivos móviles. Para ello utiliza la etiqueta autocerrada < img> (con atributos src, alt, width y height), así como las etiquetas < video> y < audio>, las cuales comparten atributos clave como src para la ruta del archivo, controls para habilitar el reproductor, autoplay para inicio automático, loop para reproducción en bucle y muted para silenciar el sonido inicial.
