En HTML, una etiqueta (tag) es la marca delimitada por < > que señala el inicio o el final de un componente (como < p> o < /p>), mientras que un elemento abarca todo el conjunto: la etiqueta de apertura, el contenido y la etiqueta de cierre (como < p>Aquest és un paràgraf.< /p>). Estos elementos se pueden anidar colocando unos dentro de otros, siendo fundamental respetar la jerarquía de cierre para mantener el orden correcto (la primera etiqueta que se abre es la última que debe cerrarse).
