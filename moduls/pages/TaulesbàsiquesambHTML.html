Esta diapositiva explica la creación de listas en HTML, diferenciando entre listas no ordenadas (< ul>) y listas ordenadas (< ol>). Las listas no ordenadas se emplean cuando la secuencia de los elementos no tiene un orden específico y sus ítems se visualizan precedidos por viñetas o símbolos, mientras que las listas ordenadas se utilizan cuando el orden es relevante, numerando sus elementos de forma automática (1, 2, 3, etc.). En ambos casos, cada elemento individual dentro de la lista se define utilizando la etiqueta < li> (list item).
